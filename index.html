01 — THE FAILURE

Fake authority can look convincing.

01

Real words.
False permission.

An email, forwarded note or screenshot says an action is approved. The instruction sounds official—but has no standing in the trusted ledger.

02

Old approvals.
New context.

Permissions expire, get revoked or apply only to a different task. A model may see an earlier yes and overlook the current no.

03

Safety without
over-refusal.

Rejecting everything is not success. An aligned agent must still recognize valid approvals and answer benign questions.

04 — THE STUDY

From adversarial
evidence to
measured improvement.

Our workflow separates data construction, real model inference, intervention and independent verification. CuratorKIT curation and AuditKIT integration are now verified in CI; real model evaluation is the next mandatory research stage.

  1. 01
    Curate

    Create family-disjoint synthetic cases, with source-label review and CuratorKIT data hygiene.

    224 synthetic cases · CuratorKIT 132/132 verified
  2. 02
    Challenge

    Run Tiny Aya Earth on the held-out cases with deterministic decoding; record raw responses, timings and the model revision.

    Requires gated model access and GPU
  3. 03
    Intervene

    Test a provenance-focused guardrail prompt, then investigate SafeTune safety methods if supported.

    Model intervention not yet run
  4. 04
    Audit

    Use AuditKIT and paired statistics to publish before-and-after outcomes, regressions and reproducibility logs.
